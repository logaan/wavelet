# Compiler as a component and compiled browser REPL

After the review/refactor checkpoint, expose a shared filesystem-free compiler through WIT as a WebAssembly component. Use the same compiler path as the CLI. Accept explicit source, WIT and macro inputs; automatic macro registry fetching is not a goal. Build a browser execution layer and reusable compiled REPL used throughout the documentation website. Verify native/component/browser behavior and errors, supplied macro components, persistent definitions, cancellation and timeouts. No interpreter fallback.
