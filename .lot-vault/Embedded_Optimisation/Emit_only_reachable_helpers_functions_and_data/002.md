Per user direction, adopt Binaryen rather than maintain custom general reachability/DCE. A draft custom pass was reverted before measurement. The final compiler-specific change (5287c43) conservatively omits printer code/static strings when expanded application forms have no to-string/gensym use; macro libraries retain compile-time printing. Binaryen removes remaining unused functions in size builds. Stage-three marginal size savings: minimal 227, WASI 234, collections 0 (uses formatting), kb portfolio 1660 bytes. Default output gains are larger because Binaryen already removed dead printer bodies in earlier size checkpoints. This is not full static-data reachability: whole-arena gate can conservatively retain unused printing and portable/browser builds do not run Binaryen. Report: benchmarks/artifact-size/RESULTS.md.
