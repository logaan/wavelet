# Emit only reachable helpers functions and data

The old emitter emitted every runtime helper and associated static strings, even for a scalar constant. Casing was removed separately; other helper and data retention remains.

Compute reachability from exported functions, required ABI support, resources, start/initialisation paths, closures and indirect-call targets. Emit only reachable user functions and support helpers, and attach static data to its actual users. Avoid whole-arena symbol scans and preserve required side effects and host imports.

Acceptance: unused user functions and helpers do not affect component size; a scalar constant includes no printing/collection/allocator support unless actually required; indirect calls and resources remain correct; tests inspect emitted sections and execute representative programs. Keep compiler/browser outputs reproducible.
