# Eliminate avoidable allocation copying and intermediate collections

After typed calls are available, remove redundant boxing, copying and temporary collections within a component. Moving convenience operations to an explicit standard library must not prevent these optimisations.

Add escape/lifetime analysis, scalar replacement, reusable temporary storage, in-place updates when uniquely owned, and direct canonical-layout results where safe. Specialise and inline higher-order library calls. Fuse map/filter/fold pipelines or offer an explicit streaming/iteration representation to avoid materialising intermediates. Preserve observable callback order, traps and mutation semantics; do not assume purity without proof.

Acceptance: a map-then-fold pipeline can run without intermediate list allocation when legal; nonescaping records are scalarised; unique updates avoid full copies; aliased values retain their original value; benchmarks show bounded per-iteration temporary memory and report copy/allocation reductions. Keep fallbacks for programs where optimisation is unsafe.
