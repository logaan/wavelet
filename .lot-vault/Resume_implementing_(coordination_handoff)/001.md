## Operational gotchas

- **`lot` CLI:** always `LOT_VAULT_PATH=/Users/logaan/code/personal/rust/wavelet/.lot-vault`;
  pass update bodies via **stdin only** (`echo ... | lot update ...` or
  `< file`) — the `-- "body"` form hangs and wedges the vault lock (kill the
  stuck process to recover). `lot` commits to the shared checkout's main; that is
  expected.
- Subagent Edit/Write tools may be rejected ("parent bg session hasn't
  isolated") — agents fall back to Bash-applied patches inside their worktree;
  tell them this up front.
- `git checkout <file>` in a worktree discards uncommitted work — commit before
  any instrumentation/cleanup.
- Agents stall (stream watchdog, no progress ~600s). Work survives if committed.
  Resume via a message to the same agent; if its context is exhausted, spawn a
  fresh session agent from the goal-Thing checkpoint instead.
- **Verification gates** (per CLAUDE.md): `cargo test`, the differential harness,
  the conformance suite (`conformance/`), `./scripts/regen-examples.sh` when
  example-visible behaviour changes, CHANGELOG `[Unreleased]`, and downstream
  surfaces (docs prose, Prism grammar, the wavelet.nvim submodule — commit AND
  push inside it + stage the pointer, VS Code grammar, wavelet-lsp).
