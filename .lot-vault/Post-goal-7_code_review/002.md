## The 3–5 to do first

1. **lot:033l1yDipWHRNtlP59nmOr — compiled→interpreter fallback re-executes side
   effects (bug-risk M).** A program that prints then traps on a decision-gated
   hole prints twice (compiled run, then interpreter re-run). User-visible, and
   invisible to the differential harness. Fix: fall back only on pre-execution
   failures, not mid-run traps.
2. **lot:033l1y4sbOSrhXfOVZxLjk — persist write barrier breaks cell identity /
   no cycle guard (bug-risk M, latent).** The 5.1 barrier deep-copies cells
   (losing shared identity) and self-recurses without a visited-set (cyclic
   graph → stack-overflow trap). Narrow reachability today (functor `set` only),
   but it is the contract every future DefResource `New` depends on.
3. **lot:033l1yMmzcpsnNoo8E5i2E — differential harness coverage gap
   (test-infra M).** The oracle-agreement proof runs only documented examples and
   compares only the final `to-string`; effect streams, effect ordering, and the
   whole goal-5/6/7 resource/cell/persist surface are structurally uncovered.
   This is *why* findings 1 and 2 can hide. Add a docs-independent fixture corpus
   that diffs stdout and exercises multi-call resource state.
4. **lot:033l1y4k1Vf0nCMqGQHIVU — split emit.rs (refactor L)** and its companion
   **lot:033l1y4oni0ucmKOPCVxww — split the 1,750-line `builtin` method
   (refactor M).** Pure motion, biggest maintainability win, unblocks safer
   parallel work; concrete module boundaries proposed on the Things.
