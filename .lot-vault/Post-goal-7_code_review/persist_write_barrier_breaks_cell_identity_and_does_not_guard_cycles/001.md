# persist write barrier breaks cell identity and does not guard cycles

## What

The 5.1 persistent-region write barrier `persist(box)` (`src/emit.rs:13499`,
helper body 13505–13661) deep-copies an arena value graph into the persistent
region so resource/functor state survives the per-call arena reset. Two latent
correctness gaps:

1. **Cell identity is not preserved.** `persist` treats `TAG_CELL` as an
   ordinary node (pbase=4, pcount=1, 13604–13615): it allocates a *new*
   persistent cell and copies. If a value graph reaches the *same* arena cell by
   two paths (shared mutable cell) and that graph crosses the barrier
   (`cell-new` persists its argument, `src/emit.rs:6881`), the two references
   become two distinct persistent cells — mutating one no longer affects the
   other, diverging from the interpreter's `Rc<RefCell>` sharing.

2. **Cycles are not guarded.** `persist` is unconditionally self-recursive over
   child pointer words (loop at 13624–13656) with no visited-set. A cyclic arena
   graph (e.g. `let c (cell-new 0) (cell-set c c)` then storing `c` as resource
   state) makes `persist` recurse forever → wasm stack exhaustion trap, where the
   interpreter's reference-counted cell just works.

## Why it matters

Both are silent divergences from the interpreter (the semantics oracle) that the
differential harness cannot see (no documented example builds cyclic/shared-cell
resource state). Reachability is narrow *today* — the only shipping resource that
crosses the barrier is the functor `set`, which persists a single cell holding a
list of values — but the barrier is the contract every future `DefResource`
`New` relies on, so the gap should be closed or explicitly documented before the
resource model grows. (Distinct from the KNOWN Drop-body oracle divergence /
dead `consumed` plumbing on the DefResource decision Things.)

## Suggested change (sketch)

- Short term: document the barrier's contract (acyclic, no shared-by-identity
  cells) and add a structural check that rejects storing a cell-containing /
  potentially-cyclic graph into resource state, so it is a compile error rather
  than a silent miscompile / trap.
- Longer term: thread an identity map (arena-ptr → persistent-ptr) through
  `persist` so a repeated arena node persists once and both references share the
  copy; the same map breaks cycles. This mirrors `Rc` sharing.

## Severity / effort

bug-risk (latent) / M.
