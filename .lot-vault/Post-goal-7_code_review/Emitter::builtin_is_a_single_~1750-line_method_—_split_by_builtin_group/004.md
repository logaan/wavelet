classifier that routes each name to a per-group helper:

- builtin_numeric — eq/not/ordering/arith/neg/abs/min/max
- builtin_seq — len/head/tail/reverse/range/empty/drop
- builtin_higher_order — map/fold/filter/zip/apply

- builtin_string — str-cat/to-string/to-char/upper/lower
- builtin_variant — some/ok/err
- builtin_cell — cell-new/cell-get/cell-set
- builtin_form — form-kind/rec-key/rec-val/gensym/expand
