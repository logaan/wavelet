## Context the step must restate

`wavelet run` (`src/runner.rs`) and the REPL (`src/repl.rs`) execute
compiled-first and fall back per-entry to the interpreter with a stderr note
on the known holes. The burn-down list is exactly the differential SKIP
table (`tests/differential.rs:56`): `macro-expand` (`expand` confined to
macro libraries when building), `sf-def` / `sf-let` / `std-conv` /
`std-div-float` / `std-pi` (float to-string) + `std-char-conv` (char
to-string), `std-apply` (record-payload closure ABI — step 2),
`std-read` (`read` needs a wasm-side reader), `values-atoms` (flags-literal
emit path — step 2). The SKIP harness already fails when a listed example
starts agreeing, so entries can't go stale.

## Scope the step must cover

1. **Char to-string** in the backend `to_str` (UTF-8 encode + Rust `{c:?}`
   escape set, single quotes; hand-built vectors asserted against
   `src/value.rs::print_value`; matches the oracle's printable-table
   behaviour). Per 0.2's answer this is likely first and independent.
2. **Float to-string** per 0.2's answer (recommended shape: a Rust helper
   compiled into the runtime implementing shortest-round-trip `{f:?}`
   exactly, nan/inf/-inf mirrored first; hand-built vectors — the harness
   cannot discriminate on its own).
3. **`read`** per 0.6's answer (guest-side reader / host import / static
   confinement + example rewrite).
4. **`macro-expand`**: decide the end-state surfacing for `expand` outside
   macro libraries (a clear static error is the current confinement) and
   whether the documented example moves/changes.
5. **Fallback removal**: once every entry is closed or statically rejected,
   remove the fallback machinery from `runner.rs`/`repl.rs` (or reduce it to
   the pre-execution-failure rule if any entry remains by design), delete
   the per-entry stderr notes, update CHANGELOG + README/docs that describe
   the fallback.
6. NO regen-examples for pure backend `to_str` work (the differential
   harness compares dynamically); regen only if a documented example's text
   or the oracle's output format changes.

## Sequencing

Depends on step 2 (std-apply, values-atoms) and benefits from step 6's F1
typed-stage-error work if that lands first. Independent of step 3 except for
