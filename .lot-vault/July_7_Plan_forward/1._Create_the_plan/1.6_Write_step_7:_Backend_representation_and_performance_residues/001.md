## Inventory the step must cover (VERIFY each against main first — some may
have landed; drop any that have)

1. **Statically resolve arithmetic to per-width wasm ops**: arithmetic
   currently goes through generic checked i64 runtime helpers; where the
   checker knows the concrete int width, emit the width's wasm ops
   directly (with the same trap-on-overflow semantics as the oracle).
2. **Monomorphize the higher-order stdlib**: stdlib functions like
   map/filter/fold-style helpers are generic; specialize per call-site
   element type so their bodies run over canonical layouts instead of
   boxes.
3. **Per-file standard-library opt-out**: `std: false` exists at some
   granularity — verify what's implemented, finish the per-file story or
   record it as done.
4. **Large-type sizing**: canonical layout assumes a 1-byte variant
   discriminant and refuses >256-case variants; flags >32 members error on
   store/load. Implement per-type disc/bitset sizing or keep the hard
   refusal as a documented limit.
5. **Sym-headed-tuple residue on the boxed path**: a remaining boxed-path
   corner from the pattern/constructor work — locate (grep emit for the
   residue comment) and close or document.
6. **Canonical `str-cat`** (and any remaining compound builtins whose win
   exists only on the canonical result path): was deliberately deferred to
   ride with the memory/evacuation work; verify whether it landed and
   schedule if not.
7. **Alias-qualified case-ctor canonical fast path** — only if 0.4's answer
   chose it.
