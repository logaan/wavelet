Implemented user-defined DefFunctor templates with named type parameters and Instantiate expansion. Templates are file-local compile-time declarations; they are not exported generic Component Model interfaces or registry-distributed templates. Instantiation substitutes types, isolates generated names, preserves lexical shadowing, and checks argument shape/collisions. Automated examples cover multiple parameters, functions, and resource boxes containing integers and strings, including memory-spilled resource results. Documented the supported surface and scope in type-system.mdx.
