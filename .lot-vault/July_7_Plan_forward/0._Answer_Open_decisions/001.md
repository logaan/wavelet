# 0. Answer Open decisions

Each child of this Thing is one open decision. Every child is self-contained:
verified context (with repo file references), the question, options with
tradeoffs, a recommended option, and a per-option execution sketch. Nothing in
them depends on any archived Thing.

## How to answer

Leave exactly **one update on each child** naming the option you choose (e.g.
"option (a)", or for the triage decision "accept all" / "accept all except
…"). A one-liner is enough; add constraints inline if you want to adjust an
option. Once **all** children are answered, send "1. Create the plan" (this
Thing's sibling) to a Claude session — its children will read your answers and
write the top-level plan steps.

## Suggested answering order

Start with the ones that gate the most work: 0.1 (tuples — gates the values
callee), 0.3 (strict flip — gates the totality/backend end-state), 0.2
(float/char to-string — gates fallback removal). The rest are independent.
