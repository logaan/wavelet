Drop Qsyms from the language. Make `/` in a name just be syntax sugar for `-`. So `ttl/days(5)` is just another way of writing `ttl-days(5)`.

When it comes to constructing variant cases we should treat them as though they're functions that return a value of that case. So if `days(5)` is the case and its from a namespace `ttl` then it should be fine to alias `days` to `ttl-days` (in the same way that we could give another name to a function). And so `ttl/days(5)` is the same as `ttl-days(5)` and both would evaluate to `days(5)`, using the type system to know which variant the case relates to.
