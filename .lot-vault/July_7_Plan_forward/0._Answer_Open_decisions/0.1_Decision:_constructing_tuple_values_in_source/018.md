an ordinary builtin — WIT-expressible shapes, no variadics, and every one
usable as a first-class function value (`apply(tuple2 pair)`,
`map(tuple1 xs)` agree with direct calls by construction, since the fixed
arity makes the §4.2 bundle unambiguous: `tuple1` wraps its single value,
every other arity is bundle-identity). The checker enforces exact arity
statically and infers `tuple(t1 .. tN)` with no ascription; the backend
constructs boxed (TAG_TUP) and canonically in place (export results, nested,
and variant/result/record payloads via new `WitTy::Tuple` arms); `DefType`
cases shadow the names exactly like `zip`.
