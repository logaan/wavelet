# 0.6 Decision: the `read` builtin on the compiled path

**Gates: one differential SKIP entry (`std-read`) and, with it, full
interpreter-fallback removal.** Verified against main 2026-07-07.

## Context

The interpreter's `read` builtin parses WAVE text into a form value at
runtime (homoiconicity's runtime half). On the compiled path there is **no
wasm-side reader** (lexer + parser inside the guest), so any program calling
`read` traps and `wavelet run`/REPL fall back to the interpreter
(`tests/differential.rs`: `const READER: … "read needs a wasm-side reader,
not implemented"`, entry `std-read`). The guest components are hand-emitted
core wasm — the Rust lexer/reader in `src/lexer.rs`/`src/reader.rs` is not
automatically reusable inside them.

## Options

- **(a) A guest-side reader**: emit (or compile in as a runtime helper) a
  lexer+parser for WAVE text inside every component that calls `read`. Full
  fidelity with the oracle; the largest single piece of remaining backend
  work (string scanning, arena building, error reporting — all in emitted
  wasm or a linked helper). Must match `src/reader.rs` exactly, including
  reader sugar and error text.
- **(b) Host-provided `read`**: the run/REPL host satisfies a `read` import
  by calling the native reader. Cheap and exact — but components that use
  `read` stop being self-contained (they grow a host dependency a generic
  WASI runtime won't satisfy), which changes what `wavelet build` produces.
  Would need a documented story for third-party runtimes.
- **(c) Confine `read` to the interpreter surface**: keep `read` working in
  the playground/oracle, make the compiled path reject it **statically**
  (clear check-time error "read is not available in compiled components"),
  and rewrite or drop the one documented `std-read` example. Honest,
  low-cost; shrinks the language on the compiled path.
- **(d) Park**: leave the per-entry fallback for `read` programs even after
  the other holes close (fallback machinery must then stay indefinitely).

## Recommendation

Decide the *shape* now, build later inside the fallback-removal step:
**(c)** if you're comfortable with `read` being an interpreter/meta facility
(it pairs naturally with `expand`, which is already confined to macro
libraries on the build path); **(a)** if runtime `read` in shipped components
is something you actually want the language to promise. Avoid (b) — it
quietly forks the component story. (d) defeats fallback removal.

## How to answer

One update: "(a)" / "(b)" / "(c)" / "(d)".
