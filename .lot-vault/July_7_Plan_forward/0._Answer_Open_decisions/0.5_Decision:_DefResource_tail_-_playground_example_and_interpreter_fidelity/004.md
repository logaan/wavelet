Added the runnable res-counter Playground example and regenerated artifacts. The interpreter now consumes own arguments at boundaries, preserves borrowed handles, and runs each live resource destructor once during deterministic teardown, including cleanup after errors. Resource lifetime tests cover these behaviors. Internal compiled handle invalidation is not implemented: same-component calls, aliases, and callbacks transferring owned resources are rejected; local helpers must borrow, while Component Model import/export ownership is supported. This explicit supported-language restriction prevents oracle/backend divergence. The seven conformance pairings pass with the restriction.
