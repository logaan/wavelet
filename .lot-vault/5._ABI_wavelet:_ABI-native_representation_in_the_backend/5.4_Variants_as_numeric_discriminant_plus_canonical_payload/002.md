First 5.4 slice landed (96c372e): flags values. A flags literal now evaluates
in the backend to exactly the interpreter's value (Value::Flg = TAG_FLG box
of the set names, source order); boundary form is the canonical i32 bitset
(lower = membership OR over declared members; lift = set names in
declaration order). This replaced the old record-of-bools lift — a latent
oracle-parity bug (no interpreter value ever equals a record of bools) that
was unreachable only because flags were inexpressible. permissions-rt is
restored in the conformance runner and green against both rust callees;
tests/backend_flags.rs pins it in-tree.
