5.6 progress on goal-5-abi-backend: the per-type compiled shape now exists
and carries its first two builtin families.

- Scalar builtins (eq/not/lt/le/gt/ge/add..rem/neg) resolve their per-type
  path at COMPILE time from the checker's node-type table (59523e1); the
  runtime tag-switch survives only as the fallback for gradual operands, and
  its int-arithmetic/f64-compare cores are shared helpers (arith_int,
  cmp_f64) so the two paths cannot drift from each other or the oracle.
- Numeric conversions to-u8..to-s64 / to-f32 / to-f64 / to-char compile per
  operand kind with the interpreter's exact range/fraction/scalar-value
  error behaviour (849b81e). This closed the values-to-u8-ok differential
  SKIP and makes the conformance char transform compile.

builtins from the parity checklist (map/filter/fold/concat/push/reverse/
range/zip/contains/get/put/tup/flg/cell-*; to-string still traps on
