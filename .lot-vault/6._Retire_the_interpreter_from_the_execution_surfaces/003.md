## The real blocker for Step 2 and the run rider: backend coverage

The compiled backend is still a strict subset of the interpreter. The
differential SKIP list is the evidence: `to-string` traps on float/char;
missing stdlib builtins `apply / abs / to-u32 / to-u8 / map(std-map via range) /
reverse / get / split / zip / read`; `pi` unbound; flag literals rejected on the
emit path. Consequences:

- A **fully-compiled REPL** regresses hard vs today: it could not evaluate a
  line using `map`, could not print a float/char result. Unacceptable as a flip.
- **`wavelet run`** is unaffected by the float/char *to-string* trap (it discards
  the result, prints nothing) — but is still blocked because programs using any
  unimplemented builtin fail to *compile*, so a straight flip regresses on the
  common cases; a compile-if-possible-else-interp hybrid would preserve behaviour
  but keeps the interpreter (does not retire it) and is throwaway once coverage
  lands.
