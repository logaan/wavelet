## Fallback design followed (the carve-out)
Compiled-first, graceful interpreter fallback per entry/program, announced on
stderr — the shape the brief prescribed where unrecorded. On any compiled-path
failure (build error, missing `run` export, or a runtime trap on a decision-gated
hole) the surface re-runs that entry on the interpreter:
- REPL: prints the interpreter's print_value with an "(interpreter fallback: …)"
  stderr note; if the interpreter also errors, prints `error: …` and continues.
- run: if the interpreter succeeds, exit 0 + stderr note; if it also errors, the
  interpreter's clearer message is surfaced (F5 diagnostic fidelity) instead of a
  bare wasm trap. Non-regressing: everything that ran before still runs.
This keeps all 10 SKIP-listed behaviours from crashing worse: float/char
to-string (REPL float verified → 2.5 via fallback), runtime flags, record-payload
apply, std-read all route to the interpreter cleanly rather than mystery-trapping.
