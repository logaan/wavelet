# Components & composition

Each Wavelet source file becomes a WebAssembly component. Its WIT world describes the interfaces it imports and exports. Composition connects those interfaces independently of the language used to implement them.

## Anatomy of a file

A component file declares a package, imports dependencies, defines values and types, and exports its public interface:

```wavelet
Package "demo:shout@0.1.0"

Export shout
Def shout Fn {phrase: string}
  str-cat(phrase "!")
```

Inspect its interface with `wavelet wit shout.wlt`:

```wit
package demo:shout@0.1.0;

interface api {
  shout: func(phrase: string) -> string;
}

world shout {
  export api;
}
```

Typed parameters, inferred body types, and explicit export records determine signatures. Add an explicit result annotation when inference cannot establish the export's signature.

## Packages

`Package "demo:shout@0.1.0"` identifies the file's component and version. Ordinary project compilation requires a package declaration; snippet compilation supplies its own wrapper.

The standard library is available in each file. A build rejects duplicate package identities, including two versions of the same package. Resolve dependencies to one version per package before compiling.

## Imports

An import names a WIT interface. A record can specify an alias or expose its names without qualification:

```wavelet
Import "wasi:cli/environment"
Import {pkg: "demo:shout/api" as: sh}
Import {pkg: "demo:math/api" open: true}
```

An alias prefixes imported names. `sh/shout` and `sh-shout` are equivalent; `open: true` also exposes the bare name.

Imported types retain their declaring package and interface identity. Use a prefix when two interfaces declare the same type name, such as `borrow(numbers/device)` and `borrow(words/device)`. WIT `use` aliases preserve the original resource identity. Two resources with similar methods remain distinct types.

For a set of Wavelet sources, matching imports resolve to sibling packages. Other imports need supplied WIT definitions to compile and a component or host implementation to execute. WASI follows these same rules.

## Exports

A bare export publishes a definition in the default `api` interface. A record can choose a signature or another interface:

```wavelet
Export shout
Export {name: shout params: {phrase: string} result: string}
Export {name: render iface: "html"}
```

### Adopting a host world

To implement a host's entry interface, name it in `iface` and provide the corresponding WIT definition. For example, a CLI component exports `wasi:cli/run`:

```wavelet
Export {iface: "wasi:cli/run" name: run result: result}
```

An HTTP component exports `wasi:http/incoming-handler`. Other synchronous interfaces use the same mechanism. A resource-only external interface can export a matching resource declaration with a form such as `Export {iface: "acme:counter/api@1.0.0" name: counter}`.

The compiler supports synchronous primitive and compound WIT values, aliases, and resources. Async functions, futures, streams, maps, fixed-size lists, and error contexts are unsupported. Canonical memory paths reject variants or enums above 256 cases and flags above 32 members.

## Resources

A resource exposes methods while keeping its state private. Call an imported constructor to obtain a handle and pass that handle to its methods. Ownership is part of the signature: `own(resource)` transfers a handle, while `borrow(resource)` allows temporary use.

Declare your own resource with `DefResource`:

```wavelet
DefResource counter {
  New: Fn {start: u32} cell-new(start)
  value: Fn {self: counter} The u32 cell-get(self)
}
Export counter

Def make-counter Fn {start: u32} The counter counter(start)
Export make-counter
```

`Export counter` publishes the resource's constructor and members together. Free functions using the handle are exported separately. Methods borrow their receiver; local free functions receiving existing handles must use borrowed parameters.

To release an imported owned handle, use that resource's destructor binding, such as `streams-drop-output-stream(handle)`. Generic `drop(value)` only discards a value and does not invoke a resource destructor. See [resources and ownership](./language/type-system#user-declared-resources) for the complete contract.

## Project layout and external WIT

| Path | Purpose |
|---|---|
| `src/` | Wavelet component files. |
| `wit/deps/` | WIT dependency packages. |
| `wkg.lock` | Dependency version lockfile. |
| `out/` | Generated artifacts. |

`wavelet new` uses `wkg` to fetch dependency definitions. Builds consume the existing dependency tree and can refresh dependency metadata through `wkg`. Authored root WIT files and macro artifacts are preserved. Dependency packages can be WIT directories, `.wit` files, or encoded WIT in `.wasm` or `.wat` files.

WIT defines a contract; it does not supply the executable implementation. Provide runtime implementations through composition or the host. Supply executable macro components separately through the [macro import mechanism](./language/macros#importing-a-macro-library).

## Composition

Build related files together:

```console
$ wavelet build src/*.wlt -o out
```

The compiler writes individual package components. When the selected entry imports sibling packages, it also composes them into `out/app.wasm`. Compilation and composition happen in process. Unresolved external imports remain in the output for a host or later composition.

For prebuilt components, use `compose`:

```console
$ wavelet compose out/demo-main.wasm out/demo-shout.wasm -o app.wasm
app.wasm
```

The first component is the entry. Imports are connected to matching supplied exports. Calls across component boundaries use the canonical ABI and can copy data.

## Calling another language

Suppose a component written in another language exports:

```wit
package acme:words@1.0.0;
interface picker {
  pick: func(seed: u64) -> result<string, string>;
}
```

With that WIT dependency supplied, a Wavelet component can call it:

```wavelet
Package "demo:main@0.1.0"

Import {pkg: "acme:words/picker@1.0.0" as: words}

Export {name: pick-word result: string}
Def pick-word Fn {}
  Match words/pick(42) [
    (ok(word) str-cat(word))
    (err(message) str-cat("No word: " message))
  ]
```

Build the Wavelet caller, then provide the external implementation through `wavelet compose` or the application host. The caller depends on the interface, so another implementation of that contract can replace the original component.
