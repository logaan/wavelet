# Tail calls

Wavelet eliminates tail calls within a component. A call in tail position returns its result directly, allowing execution to reuse the current stack frame.

## Tail positions

A call is in tail position when it is:

- the body of a [`Fn`](./special-forms#fn);
- either result branch of [`If`](../stdlib#if);
- a clause result of [`Match`](./special-forms#match);
- the last expression of [`Do`](../stdlib#do);
- the body of [`Let`](./special-forms#let).

The compiler emits WebAssembly tail-call instructions. Your runtime must support those instructions to execute the component.

## Component boundaries

Calls to imported functions pass through canonical ABI adapters outside Wavelet's control. A recursion cycle that crosses component boundaries can consume stack even if the source call is in tail position. Keep unbounded recursive iteration within one component.
