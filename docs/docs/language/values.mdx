# Values & types

Wavelet runtime data follows the Component Model's types. The compiler checks its shape before execution:

| Type | Example | Notes |
|---|---|---|
| `bool` | `true`, `false` | No implicit truthiness. |
| `u8` to `u64`, `s8` to `s64` | `123`, `-9` | Unconstrained integer literals default to `s64`. |
| `f32`, `f64` | `3.14`, `nan`, `-inf` | Unconstrained float literals default to `f64`. |
| `char` | `'x'`, `'☃'` | A Unicode scalar value. |
| `string` | `"hello"` | Double-quoted text. |
| `tuple(...)` | `tuple2("abc" 123)` | Fixed positions may have different types. |
| `list(t)` | `[1 2 3]` | Every element has the same type. |
| record | `{x: 1 name: "Ada"}` | Named, statically known fields. |
| variant or enum | `days(30)`, `forever` | Cases declared with `DefType`. |
| `option(t)` | `some(1)`, `none` | Present or absent. |
| `result(t e)` | `ok(1)`, `err("oops")` | Success or failure. |
| flags | `{read write}` | A set of named flags. |
| resource | an opaque handle | Created by local or imported constructors. |
