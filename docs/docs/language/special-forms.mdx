# Special forms and declarations

These forms define the structure of a Wavelet program. They use [TitleCase syntax](./syntax#the-macro-sugar), with a fixed number of following forms. `If` and `Do` are bundled macros that expand to `Match`.

| Form | Arguments | Purpose |
|---|---|---|
| `Def` | name, expression | Define an immutable binding. |
| `Fn` | parameters, body | Define a function or statically resolved callback. |
| `Let` | bindings, body | Introduce sequential local bindings. |
| `Match` | value, clauses | Select a result by pattern. |
| `Quote` | form | Preserve source as data. |
| `Quasi` | form | Construct source with holes. |
| `Unquote` | expression | Insert a value into a `Quasi` form. |
| `Splice` | expression | Insert a list of forms into a sequence in `Quasi`. |
| `DefMacro` | name, parameters, body | Define a compile-time transformation. |
| `The` | type, expression | Supply an expected type. |
| `Package` | package string | Identify a component. |
| `Import` | string or record | Import an interface or macro library. |
| `Export` | name or record | Publish a function, data type, or resource. |
| `DefType` | name, type form | Declare a data type. |
| `DefResource` | name, member record | Declare a resource. |
| `Static` | function | Mark a static resource member. |
| `DefFunctor` | package string, parameters, body | Declare a file-local template. |
| `Instantiate` | record | Specialize a functor for concrete types. |

## Component-level forms

Use package, import, and export declarations to describe a complete component source file. The browser REPL accepts local definitions, types, resources, macros, and templates; package and export declarations belong in project compilation.

### `Package`

Declares the package identity and version:

```wavelet
Package "demo:shout@0.1.0"
```

### `Import`

Imports an interface. A record controls the alias, unqualified names, or macro role:

```wavelet
Import "wasi:cli/environment"
Import {pkg: "demo:text/api" as: text}
Import {pkg: "demo:math/api" open: true}
```

`macros: true` imports a compile-time macro library. `roles: {runtime macro}` enables both roles. See [macro imports](./macros#importing-a-macro-library).

### `Export`

Publishes a definition in the default `api` interface or a named interface:

```wavelet
Export shout
Export {name: shout params: {phrase: string} result: string}
Export {iface: "wasi:cli/run" name: run result: result}
```

An external interface uses its WIT signature. The compiler applies the same rules to WASI and other interfaces; the host must support the resulting contract.

### `DefType`

Declares a record, variant, enum, flags type, or alias:

```wavelet
DefType point {x: f64 y: f64}
DefType ttl [days(u32) forever]
DefType direction [north east south west]
DefType perms {read write exec}
DefType points list(point)
```

Variant and enum declarations bind their case constructors in the value namespace:

<Playground id="sf-deftype-cases" />

### `DefResource` and `Static`

`DefResource name {members}` declares a resource with a `New` constructor, optional `Drop` destructor, instance methods, and `Static Fn` members. See [user-declared resources](./type-system#user-declared-resources) for examples and ownership rules.

### `Derive`

`Derive` is not implemented. The compiler rejects it with a diagnostic; write the operations explicitly. See [Derive](./type-system#derive).

### `DefFunctor`

`DefFunctor "package" {parameters} [declarations]` declares a template in the current file. See [user-defined templates](./type-system#user-defined-templates).

### `Instantiate`

`Instantiate` specializes a functor with named type arguments:

```wavelet
Instantiate {pkg: "wavelet:coll/set" with: {elem: s32} as: ints}
```

The alias qualifies operations such as `ints/new` and `ints/add`. See [functors](./type-system#functors).
