# The type system

Wavelet checks types before a program runs. The same checking applies to builds, CLI execution, the REPL, and browser examples. A type error in an unused definition is still an error.

Runtime data uses concrete WIT types. A list has one element type, a record has known fields, and every branch of an `If` or `Match` must produce compatible results. The compiler infers types from expressions, calls, and imported signatures. Add annotations when those constraints leave a type ambiguous.

## Numeric literals and `The`

An integer literal takes its type from context when possible. Without a constraint it defaults to `s64`; a fractional literal defaults to `f64`.

Use explicit conversion functions such as `to-u8` when converting an existing numeric value. Such conversions check the value's range during execution.

## Function parameters and results

Annotate parameters in the `Fn` record:

```wavelet
Def increment Fn {n: s32} add(n 1)
```

The body determines the result type. For an exported function, an explicit `result:` also constrains the body:

```wavelet
Export {name: increment params: {n: s32} result: s32}
```

Same-signed integer results can widen to a declared result type. Narrowing and changes of signedness require explicit conversions. A declared payload-less `result` can discard the payload of `ok` or `err`; this permits an `ok(0)` body for a WIT `func() -> result` export.

`map`, `filter`, and `fold` infer callback parameters from their input lists. `fold` also uses the initial accumulator's type. A filter callback must return `bool`, and a fold callback must return the accumulator type.

## Function values

Local function aliases and capturing callbacks work when the compiler can determine the called function statically:

```wavelet
Def increment Fn {n: s32} add(n 1)
Let {f: increment} f(41)
```

Functions cannot be stored in lists, records, tuples, or cells, returned as closures, or selected dynamically for a later call. For runtime operation selection, store a variant case and use `Match` to choose a direct call. Macros can generate calls during compilation.

A function cannot cross a component boundary as a WIT value. To expose callable state, define a resource with methods. The compiler does not automatically turn a closure into a resource or treat a single-method resource as a function.

## Derive

`Derive` syntax is recognized, but its generated equality, ordering, display, and hash bodies are placeholders. Do not rely on it for data operations. Write the required functions explicitly; `eq` already compares plain data structurally.

## Functors

A functor specializes declarations for concrete type arguments. The built-in set functor creates a set resource for its `elem` type:

```wavelet
Instantiate {pkg: "wavelet:coll/set" with: {elem: s32} as: ints}

Def count-distinct Fn {}
  Let {s: ints/new()}
    Do [ints/add(s 1)
        ints/add(s 2)
        ints/add(s 1)
        ints/size(s)]
```

The result is `2`. `new` creates a mutable set; `add` inserts an element if it is absent; `contains` checks membership; `size` returns its size. Membership uses structural equality. Calls are qualified by the alias, such as `ints/contains(s 1)`.

Each instantiation emits concrete WIT types. You can instantiate sets for primitive and compound element types and use several instantiations in one component. A function can return the set handle for another component to use. When a returned set contains a local record type, the compiler places shared types in an interface that both the API and the resource interface can reference.

## User-declared resources

A resource has **identity and private state**. Callers hold an opaque handle and use its declared methods. `DefResource` declares a WIT resource; `DefType` declares data copied by structure.

<Playground id="res-counter" />

A counter can store its state in a cell:

```wavelet
DefResource counter {
  New: Fn {start: u32} cell-new(start)
  next: Fn {self: counter}
    The u32 Do [cell-set(self add(cell-get(self) 1)) cell-get(self)]
  value: Fn {self: counter} The u32 cell-get(self)
  sum: Static Fn {values: list(u32)}
    The counter counter(fold(Fn {total: u32 value: u32} add(total value) 0 values))
}
```

### Members and their roles

- `New` is the constructor. It returns the private representation, which can be plain data or one outer cell containing plain data.
- An instance method starts with `self: counter`. Within its body, `self` refers to that private representation.
- `Static Fn` declares a function belonging to the resource type without a `self` parameter. It can provide another way to construct a resource.
- Optional `Drop` supplies cleanup when the runtime destroys a handle. It is not called as an ordinary method.

The checker rejects a static with `self`, an instance method without the required receiver, and `Static` on `New` or `Drop`. Nested or shared cells, cell cycles, and functions are not supported as persisted resource state.

### Calling a resource

Apply the resource name to construct it. Qualify methods and statics with that name:

```wavelet
Def c counter(5)
Do [counter/next(c)
    counter/next(c)
    counter/value(c)]
```

This returns `7`. `counter/sum([1 2 3])` calls the static constructor. `The` is useful in members when an operation on the private representation does not provide enough information to infer the result type.

### Ownership at the boundary

A resource parameter or result carries an ownership mode:

| Type | Meaning |
|---|---|
| `counter` or `own(counter)` | Transfer ownership of the handle. |
| `borrow(counter)` | Allow the callee to use the handle for the call without transferring ownership. |

Borrowing is allowed in parameter position, not in returned or stored data. After an owned handle crosses a component boundary, the caller must not reuse it; an invalid use traps. A borrowed call leaves ownership with the caller.

Inside a component, a free function or callback receiving an existing handle must use a borrowed parameter. Local calls that would transfer ownership, including ownership nested in parameter data, are rejected. Resource methods borrow their receiver, and constructors can create handles locally.

Use the imported resource's destructor binding to release an imported owned handle. The generic `drop(value)` only discards its argument and returns unit; it does not invoke a resource destructor.

### Identity, printing, and serialization

Resource equality compares identity. Two separately constructed counters differ even if their states match. Printing a counter yields `<counter>` without exposing its state. A resource handle cannot be serialized as a source form and reconstructed from that text.

### Exporting a resource

A bare `Export counter` publishes the constructor, methods, and statics together in the default `api` interface. `Export {iface: "counters" name: counter}` places it in a named interface. An unexported resource stays internal to the component.

Free functions using the resource are exported separately:

```wavelet
Export counter

Def make-counter Fn {start: u32} The counter counter(start)
Export make-counter

Def bump-counter Fn {c: borrow(counter)} The u32 counter/next(c)
Export bump-counter
```

The corresponding WIT exposes the resource and those functions:

```wit
interface api {
  resource counter {
    constructor(start: u32);
    next: func() -> u32;
    value: func() -> u32;
    sum: static func(values: list<u32>) -> counter;
  }
  make-counter: func(start: u32) -> counter;
  bump-counter: func(c: borrow<counter>) -> u32;
}
```

Imported resources use the same ownership rules. Their identity comes from the declaring WIT interface, so two unrelated resources cannot be interchanged merely because their methods look alike.

## User-defined templates

`DefFunctor` declares a file-local template. Its package string identifies it, its flags list the type parameters, and its body contains declarations. `Instantiate` supplies the arguments by name and prefixes the generated names:

```wavelet
DefFunctor "demo:box" {elem} [
  Export box
  DefResource box {
    New: Fn {value: elem} cell-new(value)
    get: Fn {self: box} The elem cell-get(self)
  }
  Def unwrap Fn {value: elem} box/get(box(value))
  Export {name: unwrap params: {value: elem} result: elem}
]
Instantiate {pkg: "demo:box" with: {elem: s64} as: numbers}
Instantiate {pkg: "demo:box" with: {elem: string} as: words}
```

This generates independent `numbers-box` and `words-box` resources, plus concrete `numbers-unwrap` and `words-unwrap` functions. Type arguments can also be compound types such as `list(s64)`.

<Playground id="ty-user-functor" />

Templates support `Def`, `DefType`, `DefResource`, and `Export` declarations. They cannot contain imports, nested templates, or template instantiations. Define and instantiate a template in the same file, or in the same submitted REPL source. Missing, extra, or duplicate arguments and generated-name collisions are errors. Generated declarations pass through the same checker as handwritten code.
