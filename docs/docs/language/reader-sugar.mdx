# Reader sugar

The reader rewrites a small set of convenient spellings into ordinary source forms. These rules run before macro expansion. `wavelet read` prints the result, making it useful when writing macros or checking how a form is grouped.

## 1. Commas are whitespace

These lists read identically:

```wavelet
[1 2 3]
[1, 2, 3]
```

The canonical printer includes commas:

```console
$ echo '[1 2 3]' | wavelet read
[1, 2, 3]
```

## 2. The attachment rule (call forms)

An attached parenthesis turns a name and its arguments into one call form:

| Source | Canonical form | Arguments |
|---|---|---|
| `f(x)` | `(f, x)` | One value. |
| `f(x y)` | `(f, x, y)` | Two positional values. |
| `f([x y])` | `(f, [x, y])` | One list. |
| `f({a: 1 b: 2})` | `(f, {a: 1, b: 2})` | One record. |
| `f()` | `(f)` | None. |

With whitespace, `f (x)` contains two separate forms. A standalone `(x)` is a zero-argument call in expression position, not grouping around `x`.

## 3. Qualified calls

A slash in a name normalizes to a hyphen. `kv/get` and `kv-get` name the same binding. Multiple segments work too: `service/cache/get` becomes `service-cache-get`.

```console
$ echo 'kv/get(42)' | wavelet read
(kv-get, 42)
```

Imports bind functions under their alias prefix. Slash spelling is optional; it does not create a separate namespace. The same rule applies to a local alias:

```wavelet
DefType ttl [days(u32) forever]
Def ttl-days days
ttl/days(5)
```

## 4. Call chaining

A chain inserts its receiver as the first argument. The dot, following name, and opening parenthesis must be attached:

| Source | Canonical form |
|---|---|
| `1.increment()` | `(increment, 1)` |
| `x.foo(a b)` | `(foo, x, a, b)` |
| `foo(1).bar(2)` | `(bar, (foo, 1), 2)` |

Each additional call wraps the preceding result. `"hello".str-cat(", world").str-cat("!")` therefore means `str-cat(str-cat("hello" ", world") "!")`.

## 5. TitleCase macro sugar

A name containing a word with an initial capital and lowercase letters uses macro syntax. Ordinary all-lowercase or all-uppercase WIT words do not: `parse-JSON` remains an ordinary name.

| Source name | Canonical head |
|---|---|
| `If` | `if-MACRO` |
| `DefMacro` | `defmacro-MACRO` |
| `Try-let` | `try-let-MACRO` |
| `TryLet` | `trylet-MACRO` |
| `lib/Identity` | `lib-identity-MACRO` |

Interior capitals do not insert hyphens. Define `try-let` to use `Try-let`, or `trylet` to use `TryLet`.

The reader uses the declared arity to consume following forms:

```console
$ echo 'If eq(1 1) "yes" "no"' | wavelet read
(if-MACRO, (eq, 1, 1), "yes", "no")
```

Define or import a macro before use. Each nested macro consumes its own arguments. An attached payload supplies arguments explicitly, so `If(c t e)` has the same structure as `If c t e`.

## At a glance

| Rule | Example | Effect |
|---|---|---|
| Optional commas | `[1 2 3]` | Read as `[1, 2, 3]`. |
| Attached calls | `f(x y)` | Place the head before the arguments in a tuple. |
| Qualified names | `kv/get(x)` | Normalize `/` to `-`. |
| Chaining | `x.f(y)` | Insert the receiver first. |
| TitleCase forms | `If c t e` | Consume the macro's known number of arguments. |

See [syntax](./syntax) for lexical rules and [evaluation](./evaluation) for how these forms behave after compilation.
