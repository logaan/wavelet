# Wavelet

Wavelet is a small, statically typed language that compiles to **WebAssembly components**. Each source file becomes a component with a typed interface. You can compose it with components written in other languages and run the result on a compatible host.

Wavelet uses the Component Model's data types: booleans, numbers, strings, lists, records, variants, and resource handles. [WIT](https://component-model.bytecodealliance.org/design/wit.html) describes the functions and types that cross component boundaries. Calling an imported function uses the same syntax as calling a local function.

Its source syntax builds on [WAVE](https://github.com/bytecodealliance/wasm-tools/tree/main/crates/wasm-wave), the Component Model's text format for values. Code can also be treated as data, which lets macros transform source forms during compilation.

## Try it

Edit an example and choose **Run**, or press `Cmd`/`Ctrl`+`Enter`. The compiler runs in a browser worker, produces a component, and executes that component. You can also open the [browser REPL](/repl) to write a larger program.

The compiler checks that lists have one element type, that branches return compatible types, and that matches cover the input type. Inference supplies types where there is enough context; annotations resolve ambiguous cases.

## A component in one file

Save this as `shout.wlt`:

```wavelet
Package "demo:shout@0.1.0"

Export shout
Def shout Fn {phrase: string}
  str-cat(upper(phrase) "!")
```

`Package` identifies the component, `Def` defines a function, and `Export` makes it available to callers. Build it with:

```console
$ wavelet build shout.wlt -o out
```

Another component can import and call it:

```wavelet
Package "demo:greeting@0.1.0"

Import {pkg: "demo:shout/api" as: sh}

Export {name: greet result: string}
Def greet Fn {name: string}
  str-cat("Hello, " sh/shout(name))
```

Build both files together to compose the matching import and export. A host supplies any remaining interfaces, such as filesystem access or HTTP requests. The browser REPL runs components whose runtime imports can be resolved without host capabilities; supplying WIT describes an interface but does not implement it.
